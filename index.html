Task 2: Selectors and Priority

Given code:

<div id="header">
  <span class="myclass1">Every</span>
  <span class="myclass2">one can</span>
  <span class="myclass3">success.</span>
</div>

<p> One machine can do the work of fifty ordinary men.
  <span class="myclass4">No machine can do the work of one extraordinary man.</span>
</p>

<style>
   p > span { color: red; }
   #header span { color: pink; }
   span { color: green; }
   #header *:last-child { color: orange; }
   #header span:first-child:hover { color: blue; }
</style>

Live result (hover over the words to check the answers):

Answer

color color when mouse over
span.myclass1 pink blue
span.myclass2 pink pink
span.myclass3 orange orange
span.myclass4 red red

Explanation

  • myclass1: #header span (1,0,1) beats span (0,0,1), so it is pink. It is the first child, so on hover #header span:first-child:hover (1,2,1) wins and it turns blue.
  • myclass2: it is neither the first nor the last child, so only #header span applies. It stays pink, even on hover.
  • myclass3: it is the last child, so #header *:last-child (1,1,0) beats #header span (1,0,1) and it is orange. The hover rule needs :first-child, so it stays orange.
  • myclass4: it is outside #header and a direct child of <p>, so p > span (0,0,2) beats span (0,0,1). It is red, with no hover change.
